## 📌 Repository Overview

This repository documents my journey of learning and practicing Java programming. It covers core language concepts, object-oriented programming, exception handling, and problem-solving techniques.

### Topics Covered

- **Java Fundamentals:** Data types, operators, control structures, loops, arrays, and methods.
- **Object-Oriented Programming (OOP):** Classes, objects, encapsulation, inheritance, polymorphism, abstraction, and interfaces.
- **Exception Handling & I/O:** Exception handling, `try-catch-finally`, file handling, and standard input/output.
- **Data Structures & Algorithms:** Arrays, linked lists, recursion, searching, sorting, and other algorithmic problems.
- **Practical Programs:** Small programs and exercises to strengthen Java programming skills.

## ⚙️ Getting Started

### Prerequisites

Install the Java Development Kit (JDK 17 or higher recommended).

Verify your installation using the following commands:

```bash
java -version
javac -version
```

### Installation

Clone the repository:

```bash
git clone https://github.com/stevejs-droid/Java.git
```

Navigate to the project directory:

```bash
cd Java
```

### Compiling and Running a Program

Navigate to the directory containing your Java source file and compile it:

```bash
javac FileName.java
```

Run the compiled program:

```bash
java FileName
```

**For programs that use packages:** Compile and run them from the appropriate project root, using the fully qualified class name when necessary.
